# Видео для баннера на странице входа

Положить сюда файлы (имена важны — на них ссылается `index.html`):

- `tire-banner.webm` — основной (лёгкий) вариант
- `tire-banner.mp4` — запасной для Safari/iPhone
- `tire-banner-poster.jpg` — кадр-заставка, пока видео грузится (по желанию)

Рекомендации: 1280×720, 10–20 секунд, без звука, бесшовный цикл, до ~3 МБ.
Пока файлов нет, слева показывается CSS-фон с «протектором».
