# MASTERSHINA ПО — SM AVTO BASE

Внутренняя система управления компанией MASTERSHINA (продажи, финансы, склад, документы).
Образец, с которого повторяется интерфейс: https://mastershina.cloudplus.uz/

Сайт: https://alex22826.github.io/mastershina-po/

## Что готово

- **Страница входа** (`index.html`) — копия оригинала: видео-баннер слева, форма справа,
  кнопка START с неоновой подсветкой, переключатель RU/UZ с плавной сменой текста,
  карточки разделов. На телефоне видео уходит фоном под форму.
- Вход пока не работает (как и в оригинале): при нажатии START показывается
  «Личный кабинет пока в разработке». Логин и пароль никуда не отправляются.

## Структура

```
index.html               — страница входа
favicon.svg
assets/css/base.css      — общие цвета/шрифты для всех страниц системы
assets/css/login.css     — стили страницы входа
assets/js/i18n.js        — перевод RU/UZ (общий движок)
assets/js/login.js       — логика страницы входа + её строки RU/UZ
assets/video/            — сюда класть видео баннера (см. README внутри)
```

## Как запустить локально

```
python -m http.server 8820
```

и открыть http://localhost:8820/

## Обновление кэша

После правок CSS/JS увеличивайте `?v=N` в ссылках в `index.html`,
иначе браузер может показывать старую версию.
