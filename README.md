# MASTERSHINA ПО — SM AVTO BASE

Учётная система для SM AVTO BASE по ТЗ v1.0 от 07.10.2026: шины, автозапчасти и сопутствующие товары,
магазины и склады, поступления, продажи, оплаты, долги, расходы, доставка, документы и отчёты.

- Вход: https://alex22826.github.io/mastershina-po/
- УИ-кит (стили, шрифты, кнопки, формы, сайдбар, тосты): https://alex22826.github.io/mastershina-po/styleguide.html
- Образец страницы входа: https://mastershina.cloudplus.uz/

## Что умеет интерфейс

- **Тема по времени:** светлая с 8:00 до 18:00, тёмная с 18:00 до 8:00. Ручная смена действует до следующего
  переключения. Смена идёт плавной «волной» от кнопки (View Transitions), без неё — мягким затуханием.
- **Три языка:** русский, узбекский (латиница) и узбекский (кириллица). Выбор — выпадающим списком в шапке
  (на входе — переключатель RU / UZ / ЎЗ), язык общий для входа и системы (`ms_lang`).
  Переводчик `i18n-admin.js` следит за страницей и подменяет текст по словарю `lang-uz.js`.
  Кириллица получается транслитерацией латиницы. Данные (имена, товары, адреса) не переводятся.
- **Сайдбар-«рельс»:** свёрнут до иконок и раскрывается при наведении поверх страницы, не сдвигая контент.
  На телефоне — выезжающее меню и нижняя навигация.
- **Тосты справа снизу** на все действия: создание, оплата, удаление, ожидание и скачивание файла, курс, ошибки.
- **Суммы:** разряды через пробел (20 000, 200 000 000), предел ввода (оплата — не больше долга).
- **Изменить / удалить** (карандаш и корзина с подтверждением) у продаж, контрагентов, товаров, остатков и пользователей.
- **Плашка «На сайт внесены изменения — обновите страницу»** появляется, когда `version.json` на сервере
  отличается от `SM.APP_VERSION` в `app.js`. При выкладке новой версии меняйте оба значения.

## Демо-данные

Минимальный набор, чтобы было понятно, как всё работает:

- 2 контрагента: ООО «Toshkent Taxi Servis» и физлицо Азиз Рахимов;
- 2 продажи: СП-0001 (перечисление подтверждено, доставка, «Готово к отгрузке») и
  СП-0002 (наличные на проверке у бухгалтера, «Ожидает оплаты»);
- 5 товаров на складе, 3 расхода компании.

Данные хранятся в браузере (localStorage, ключ `sm.db.v1`), даты сдвигаются к сегодняшнему дню.
Сброс: «Справочники → Демо-данные». В рабочей версии нужен сервер с базой (ТЗ 22).

## Структура

```
index.html                 — вход (копия mastershina.cloudplus.uz + проверка логина, RU / UZ / ЎЗ)
admin.html                 — система (одна страница, маршруты #/раздел)
styleguide.html            — УИ-кит
version.json               — версия сборки для плашки «обновите страницу»
assets/css/base.css        — токены страницы входа
assets/css/login.css       — страница входа
assets/css/admin.css       — дизайн-система админки (две темы, компоненты, адаптив)
assets/fonts/              — Onest, Exo 2 и JetBrains Mono (локально)
assets/js/i18n.js          — переводы страницы входа
assets/js/core.js          — данные, роли и права, расчёты, операции
assets/js/data.js          — демо-данные
assets/js/ui.js            — компоненты: окна, тосты, поля сумм, графики, Excel, печать
assets/js/lang-uz.js       — словарь RU → UZ для системы
assets/js/i18n-admin.js    — переводчик системы (UZ и ЎЗ)
assets/js/app.js           — сайдбар, шапка, тема, язык, маршруты, поиск
assets/js/pages/*.js       — разделы
assets/video/              — видео баннера входа
```

## Запуск локально

```
python -m http.server 8820
```

и открыть http://localhost:8820/

После правок CSS/JS увеличивайте `?v=N` в ссылках в html — иначе браузер покажет старую версию.
