# MASTERSHINA ПО — SM AVTO BASE

Учётная система для SM AVTO BASE по ТЗ v1.0 от 07.10.2026: шины, автозапчасти и сопутствующие товары,
магазины и склады, поступления, перемещения, продажи, оплаты, долги, расходы, доставка, документы и отчёты.

- Вход: https://alex22826.github.io/mastershina-po/
- УИ-кит (стили, шрифты, кнопки, формы, сайдбар): https://alex22826.github.io/mastershina-po/styleguide.html
- Образец страницы входа: https://mastershina.cloudplus.uz/

## Доступы

Логины и пароли 6 ролей лежат в `ACCESS.txt` (файл не попадает в git).
В коде хранятся только SHA-256 хэши паролей (`login:пароль:sm-avto`).

| Роль (ТЗ 3) | Логин | Что видит |
|---|---|---|
| Администратор | `admin` | всё, пользователи, права, справочники |
| Руководитель | `rukovoditel` | сводка, продажи, оплаты, долги, расходы, касса, отчёты |
| Продавец | `prodavec`, `prodavec2` | свои продажи, клиенты, товары и остатки, скидка до 10% |
| Сотрудник склада | `sklad` | приём, перемещение, списание, сборка и отгрузка |
| Бухгалтер | `buhgalter` | подтверждение оплат, касса и банк, долги, акты сверки, НДС |
| Сотрудник по доставке | `dostavka` | доска доставки: водитель, автомобиль, стоимость, статус |

## Демо-данные

Ровно **5 тестовых продаж**, по одной на основные сценарии:

1. СП-0001 — таксопарк, перечисление, доставлено → «Завершено»
2. СП-0002 — физлицо, наличные + карта (комбинированная оплата) → «Готово к отгрузке»
3. СП-0003 — грузовые шины в $, продажа в долг, частичная оплата → «Частично оплачено»
4. СП-0004 — заказ с сайта, QR-оплата на проверке у бухгалтера → «Ожидает оплаты»
5. СП-0005 — черновик, товар в резерве

Данные хранятся в браузере (localStorage, ключ `sm.db.v1`), даты сдвигаются к сегодняшнему дню.
Сброс: «Справочники → Демо-данные». В рабочей версии нужен сервер с базой (ТЗ 22).

## Структура

```
index.html                 — вход (копия mastershina.cloudplus.uz + проверка логина)
admin.html                 — система (одна страница, маршруты #/раздел)
styleguide.html            — УИ-кит
assets/css/base.css        — токены страницы входа
assets/css/login.css       — страница входа
assets/css/admin.css       — дизайн-система админки (токены, компоненты, адаптив)
assets/fonts/              — Manrope и JetBrains Mono (локально)
assets/js/core.js          — данные, роли и права, расчёты, операции
assets/js/data.js          — демо-данные
assets/js/ui.js            — компоненты: окна, списки, графики, Excel, печать
assets/js/app.js           — сайдбар, шапка, маршруты, поиск
assets/js/pages/*.js       — разделы
assets/video/              — видео баннера входа
```

## Запуск локально

```
python -m http.server 8820
```

и открыть http://localhost:8820/

После правок CSS/JS увеличивайте `?v=N` в ссылках в html — иначе браузер покажет старую версию.
